Quellcode auf GitHub

linksta GitHub

Deine ILIAS-Kurse, offline auf dem Rechner.

linksta lädt alle Dateien deiner Kurse herunter und holt mit einem Befehl nur das, was neu ist. Für macOS, Linux und Windows.

~ $ linksta pull── Explainable AI Lecture ─────────────────  ＋ Slides/VL-05-Concept-based-Explanations.pdf 5,5 MB  ↻ Slides/VL-04-Concept-based-Explanations.pdf 5 MB✓ 1 neu, 1 aktualisiert (5 Dateien, 10,5 MB geladen)── Wissenschaftstheorie WS2026 ────────────  ＋ Vortragsliste.pdf 78,3 KB  ⚠ Konflikt: Skript.pdf – deine Version wurde als    Skript (lokal 2026-11-06 14-30).pdf behalten.✓ 1 neu, 1 Konflikt(e) (4 Dateien, 1,2 MB geladen)

Installieren

linksta ist eine einzelne Programmdatei. Du musst nichts weiter installieren, auch kein .NET.

  1. Lade die passende Datei von der Release-Seite: linksta-osx-arm64.tar.gz für Apple-Silicon-Macs (M1 und neuer), linksta-osx-x64.tar.gz für Intel-Macs. Welche du brauchst, steht im Apple-Menü unter „Über diesen Mac“ bei „Chip“.
  2. Entpacken und in einen Ordner legen, der im Suchpfad liegt: 
    mkdir -p ~/.local/bin
tar -xzf ~/Downloads/linksta-osx-arm64.tar.gz -C ~/.local/bin
  3. macOS blockiert Programme aus dem Internet, die nicht von Apple beglaubigt sind. Gib linksta einmalig frei: 
    xattr -d com.apple.quarantine ~/.local/bin/linksta
  4. Falls linksta danach nicht gefunden wird, fehlt der Ordner im Suchpfad: 
    echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
  1. Lade linksta-linux-x64.tar.gz (bzw. linux-arm64 für Raspberry Pi & Co.) von der Release-Seite und entpacke sie: 
    mkdir -p ~/.local/bin
tar -xzf ~/Downloads/linksta-linux-x64.tar.gz -C ~/.local/bin
  2. Damit linksta dein Passwort im Schlüsselbund speichern kann, brauchst du secret-tool. Ohne das Programm landet es in einer Datei, die nur du lesen kannst. 
    sudo apt install libsecret-tools   # Debian/Ubuntu
sudo dnf install libsecret         # Fedora
  3. Falls linksta nicht gefunden wird: 
    echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
  1. Lade linksta-win-x64.zip von der Release-Seite und entpacke linksta.exe nach %USERPROFILE%\bin.
  2. Ordner zum Suchpfad hinzufügen, in PowerShell: 
    [Environment]::SetEnvironmentVariable("Path", $env:Path + ";$env:USERPROFILE\bin", "User")
    Danach ein neues Terminal öffnen.
  3. Beim ersten Start kann Windows SmartScreen warnen, weil das Programm nicht signiert ist. Klicke auf „Weitere Informationen“ und dann „Trotzdem ausführen“.

Aus dem Quellcode bauen

Mit installiertem .NET 10 SDK:

git clone https://github.com/K1ngGrim/linksta && cd linksta
./install.sh          # baut und kopiert nach ~/.local/bin

Einrichten

Einmalig ausführen. linksta fragt alles Nötige ab und prüft sofort, ob die Anmeldung klappt.

linksta init
  1. URL: Füge irgendeinen Link aus deinem ILIAS ein, zum Beispiel aus der Adresszeile. linksta ermittelt daraus Server und Client-ID selbst.
  2. Benutzername und Passwort: dieselben wie beim ILIAS-Login im Browser.
  3. Sync-Ordner: wo die Kurse landen sollen. Standard ist ~/ILIAS.
  4. Passwort speichern: Mit „y“ legt linksta es im Schlüsselbund deines Systems ab, damit du es nicht jedes Mal eingeben musst.

Kurse auswählen

Am schnellsten geht es über deine Kursliste aus dem Dashboard. Mit Leertaste wählst du Kurse an und ab, mit Enter übernimmst du die Auswahl.

linksta courses

Einzelne Kurse kannst du auch per Link hinzufügen, zum Beispiel aus der Adresszeile oder dem Permalink unten auf der Kursseite:

linksta add "https://ilias.h-ka.de/goto.php/crs/1106436"

Oder du klickst dich mit linksta browse durch das Magazin, also durch Fakultät, Studiengang und Kurs.

Kurse mit 🌐 haben ein „/“ im Titel, zum Beispiel „WS 2026/27“. Solche Kurse blendet ILIAS über WebDAV aus. linksta lädt sie dann automatisch über die normale Weboberfläche. Für dich ändert sich dabei nichts.

Aktualisieren

Lädt neue und geänderte Dateien aus allen Kursen. Was sich nicht verändert hat, wird nicht erneut geladen.

linksta pull

Nur einen Kurs aktualisieren? Ein Teil des Namens reicht: linksta pull wissen. Mit linksta status siehst du vorher, was sich geändert hat, ohne etwas herunterzuladen.

Was die Zeichen bedeuten

＋
neue Datei auf ILIAS
↻
auf ILIAS geändert und neu geladen
⚠
Konflikt: Du hast die Datei bearbeitet und auf ILIAS gibt es eine neue Version. Beide bleiben erhalten.
✎
von dir bearbeitet, auf ILIAS unverändert. Deine Version bleibt, wie sie ist.
⌫
auf ILIAS gelöscht. Lokal bleibt die Datei, bis du --prune nutzt.

Deine Dateien sind sicher

linksta überschreibt nie, was du selbst geändert hast. Anmerkungen in einem PDF bleiben also erhalten. Gibt es gleichzeitig eine neue Version auf ILIAS, liegt deine daneben als Datei (lokal …).pdf. Was auf ILIAS gelöscht wurde, verschiebt linksta pull --prune in den Papierkorb ~/ILIAS/.linksta/trash. Endgültig gelöscht wird nichts. Hochgeladen wird ebenfalls nie etwas.

Offline arbeiten

Alle Dateien sind normale Dateien in deinem Sync-Ordner. Du kannst sie mit jedem Programm öffnen, auch ohne Internet. Ein paar Befehle helfen beim Wiederfinden:

linksta recent             # was ist diese Woche neu dazugekommen?
linksta search übungsblatt # Dateinamen in allen Kursen durchsuchen
linksta search "*.pdf" -c wissen --open
linksta open wissen        # Kursordner im Finder/Explorer öffnen

Große Videos brauchst du nicht? Schließe sie aus, für alle Kurse oder nur für einen:

linksta exclude add "*.mp4"
linksta exclude add Aufzeichnungen -c "Explainable AI"
linksta config set max-size 200   # nichts über 200 MB laden

Hilfe zu jedem Befehl bekommst du mit linksta <befehl> --help.

Automatisch syncen

Damit du nie wieder an pull denken musst, lass es stündlich laufen. Mit -q gibt linksta nur neue Dateien und Fehler aus.

macOS und Linux

Öffne die Crontab mit crontab -e und füge diese Zeile hinzu:

0 * * * * $HOME/.local/bin/linksta pull -q >> $HOME/ILIAS/.linksta/cron.log 2>&1

Windows

schtasks /Create /SC HOURLY /TN linksta /TR "%USERPROFILE%\bin\linksta.exe pull -q"

Wenn etwas hakt

„Anmeldung fehlgeschlagen (401)“

Benutzername oder Passwort stimmen nicht. Nutze dieselben Daten wie im Browser und speichere das Passwort mit linksta login neu. Meldet sich deine Hochschule nur über Shibboleth/SSO an, musst du im ILIAS-Profil ein eigenes lokales bzw. WebDAV-Passwort festlegen.

Ich kenne die Client-ID nicht

Musst du auch nicht. linksta init fragt den Server selbst danach. Falls das nicht klappt: Die ID steht in vielen ILIAS-Links, etwa in goto_CLIENT_crs_123.html oder hinter client_id=.

Ein Kurs fehlt bei „courses“

Die Liste kommt aus „Meine Kurse und Gruppen“ im Dashboard. Taucht ein Kurs dort nicht auf, füge ihn per Link mit linksta add hinzu.

Der WebDAV-Link aus ILIAS funktioniert nicht

ILIAS zeigt den Link bei jedem Kurs an, verweigert aber den Zugriff, wenn der Titel ein „/“ enthält. linksta erkennt das und nutzt in diesem Fall die Weboberfläche. Solche Kurse sind in linksta list mit 🌐 markiert.

Mitten im Download abgebrochen

Kein Problem. Halb geladene Dateien werden verworfen, alles andere bleibt. Der nächste pull macht dort weiter, wo der letzte aufgehört hat.

Wo speichert linksta was?

Die Einstellungen liegen unter ~/Library/Application Support/linksta (macOS), ~/.config/linksta (Linux) bzw. %APPDATA%\linksta (Windows). Das Passwort liegt im Schlüsselbund des Systems. Sync-Status, Verlauf und Papierkorb liegen in ~/ILIAS/.linksta. Zugangsdaten gehen nur an deinen ILIAS-Server.
